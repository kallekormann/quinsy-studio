# Quinsy Studio — Getting Started

The reference is the [manual](docs/README.md). This page is the door. Each heading below is an old section, kept so older links still land, and points at the chapter that replaced it.

You talk. The agent runs `./studio`. After a product exists it runs `./studio execute <project>` until it must stop for you.
