# usage-meter

**Atomic level:** Molecule (`ui-molecule`)

A horizontal meter of named parts plus the unused remainder. Filled segments are what is used. The remainder stays hollow: the track is an outline, not a fill. Hover or focus on a segment opens a tooltip with its kind, its label, and its amount.

Styled only with semantic tokens (`border-border`, `bg-primary`, `bg-foreground`, `bg-popover`).

Pull: `./studio library pull <project> usage-meter`
