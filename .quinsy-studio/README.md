## 4. Using Quinsy Studio in Cursor

Open the repo at the studio root. Bind each chat to one product when `runtime` is `cursor`. The sentences and the Allow card are in [Hosts](docs/16-hosts.md) and [What you say](docs/15-what-you-say.md).

## 8. Managing Skills

Internal skills live under `teams/`. The map is [Skills](docs/11-skills.md). The trigger index is [skill-registry.md](teams/skill-registry.md). External packages are optional (`./studio install --with-skills`) and stay subordinate to the internal skills.

## 9. Optimizing the Process

A lesson is harvested when it is seen, and infused in a studio chat. The product chat keeps building. See [Studio learning](docs/09-hq-learning.md).

## 10. The Dual-Loop

Ideation, the product, and studio learning are three loops. Input, output, and which chat to use are in [The three loops](docs/02-three-loops.md).
