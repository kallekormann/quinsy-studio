# Sources

A session records which rows it searched or skipped. Prefer official APIs. Respect the site terms. An unofficial endpoint is never the only source for a claim. Mark those rows fragile here after a session.

## Catalog

- Reddit. Patterns: "is there a tool for", "I hate", "alternative to", "how do you handle". Public JSON where the site still allows it.
- Low-star reviews (1–3 stars): Chrome Web Store, App Store, Play, G2, Capterra, Trustpilot, and host stores (Notion, Monday.com, Figma, Make.com, Shopify, WordPress, Zapier, Slack).
- Requests: Canny, UserVoice, most-upvoted GitHub issues.
- Builder forums: Hacker News (Algolia API), Indie Hackers, Stack Overflow.
- Niche rooms: trade forums, property managers, Motor-Talk, cycling, weight loss, Facebook groups for those trades.
- Niche rooms: trade forums and the communities where the brief's users already talk.
- Local rooms in the language of the sources. A market is optional. When the human names one, check at qualification whether the problem shows up there. Do not limit the search to that market.
- YouTube comments under tutorials.
- Paid workarounds: Etsy, Gumroad, Upwork, Fiverr.
- Search: autocomplete, People also ask, Google Trends. Keyword volume when a tool is available. Traffic estimates are fragile.
- Law and deadlines when the brief names a duty. A duty counts when it is in force.

## Launches are not demand

Product Hunt, Chrome Web Store launches, BetaList, AlternativeTo, Indie Hackers, Acquire.com, and Flippa are competition and trend checks. Upvotes are not revenue. A verified sale price outweighs them.

## Host stores

Notion, Monday.com, Figma, Make.com, Shopify, WordPress, Zapier, Slack, Chrome, Webflow, Airtable, Framer. A marketplace idea scans neighboring listings: price, reviews, missing piece.
