# design / layout

Portable studio principles (not project incidents).
Matching playbook/skill: `knowledge-base/design_playbook.md`.

## Principles

- **LO-0380** 2026-10-07 :: A failed export is a visible notice. A relationship list is done only when every row is a saved document.
  - A failed export shows an error the member can see. Do not treat a silent action as done. A relationship list is finished only when each row is a saved document the member can open, not a derived label.
- **LO-0373** 2026-10-04 :: Do not restyle a second side rail until that surface is signed. The signed rail's width, padding, surface, and left border are the frame.
- **LO-0172** 2026-10-07 :: A scrolling well reserves `scrollbar-gutter: stable` when it is created, even if the list is short. Filters and longer lists must not shift cards sideways. Applies to Inbox, Notes, Knowledge Base, add-ons, and pages not built yet.
