# stripe-like-ui

Apply this aesthetic configuration when an ultra-premium, modern FinTech, or high-end business platform vibe is selected:

* **Canvas & Architecture:** Razor-sharp layout grids with absolute pixel precision. Containers use slight, elegant radiuses (`rounded-lg` or `rounded-xl`). Backgrounds are ultra-clean (`bg-white` or `bg-[#0A2540]`). Borders use microscopic, crisp separation line strengths (`border border-gray-100 dark:border-zinc-800`).
* **Typography:** Premium, highly structural geometric sans-serif (`font-sans` via `Satoshi`, `Inter`, or `Soehne`). Distinct contrast between ultra-bold section headers and perfectly weighted body text.
* **Colors & Shadows:** Highly vibrant, saturated accent gradients (Stripe Purple `#635BFF`, Electric Blue `#00D4FF`). Multi-layered, soft but structural shadows that lift components off the screen naturally (`shadow-[0_50px_100px_-20px_rgba(50,50,93,0.25),0_30px_60px_-30px_rgba(0,0,0,0.3)]`).
* **Headless UI & States:**
  * Transitions: Flawless, sweep-in mechanics using custom bezier curves (`transition-all duration-300 cubic-bezier(0.16, 1, 0.3, 1)`). Dropdowns use smooth, continuous multi-directional expanding animation boxes.
  * Active States: Hover over list items creates a smooth background tracking pill effect (`ui-active:bg-gray-50 dark:ui-active:bg-zinc-800/50 ui-active:text-blue-600`).
  * Focus: Perfectly balanced, expanding accent focus rings (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[#635BFF]/40 focus-visible:ring-offset-1`).
