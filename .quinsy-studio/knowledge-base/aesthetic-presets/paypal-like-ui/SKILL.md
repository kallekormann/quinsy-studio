# paypal-like-ui

Apply this aesthetic configuration when a mass-consumer payment system, standard banking checkout, or safe, highly accessible financial service vibe is requested:

* **Canvas & Architecture:** Symmetrical, spacious, trust-inducing layout architecture. Heavy reliance on friendly, deeply rounded pill shapes and cards (`rounded-xl` or fully rounded structures like `rounded-full` for action loops). Backgrounds are highly readable and safe (`bg-[#F5F7FA]` or pure `bg-white`).
* **Typography:** Soft, heavily readable consumer sans-serif typography (`font-sans` via `PayPal Sans`, `Open Sans`, or `Inter`). Text is scaled up for high readability and visibility.
* **Colors & Shadows:** Trustworthy enterprise blues (PayPal Deep Blue `#003087`, Bright Blue `#0079C1`). Warnings use clear semantic safety yellow or red tokens. Shadows are soft, uniform, and clear to communicate interface stack depth safely (`shadow-sm` or `shadow-md shadow-slate-200/50`).
* **Headless UI & States:**
  * Transitions: Predictable, comforting, medium-paced transitions that signal security and completion checks (`duration-250 ease-in-out`).
  * Micro-Interactions: Buttons use highly visible hover overlays and clear scale adjustments to reassure users during touch/click events (`hover:bg-[#005EA6] active:scale-[0.99]`).
  * Focus: High-visibility, thick blue focus rings for exceptional universal web accessibility (`focus-visible:outline-none focus-visible:ring-3 focus-visible:ring-[#0079C1]/50`).
