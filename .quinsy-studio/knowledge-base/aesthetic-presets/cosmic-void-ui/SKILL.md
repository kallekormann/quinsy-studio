# cosmic-void-ui

Apply this aesthetic configuration when a futuristic, deep-space, or highly advanced AI-analytical vibe is requested:

* **Canvas & Architecture:** Absolute pitch-black void canvas (`bg-black`). Borderless design strategy—containers are completely unbordered and merge directly into the canvas.
* **Typography:** Ultramodern, thin sans-serif profiles (`font-sans font-light tracking-wide` via `Inter Display` or `Linear`).
* **Colors & Shadows:** Multi-chromatic radial background glows acting as nebula clusters (`bg-[radial-gradient(circle_at_center,rgba(139,92,246,0.08)_0%,transparent_60%)]`). Separation via deep ambient depth blurred backdrops.
* **Headless UI & States:**
  * Transitions: Ethereal, floating ease-in-out transformations for popovers (`transition-all duration-700 cubic-bezier(0.16, 1, 0.3, 1)`).
  * Active States: Activated buttons or lists illuminate internally (`ui-selected:text-white ui-selected:bg-gradient-to-r ui-selected:from-purple-500/10 ui-selected:to-pink-500/10`).
  * Focus: Subtle, expanding ambient light rings (`focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-purple-500/30`).
