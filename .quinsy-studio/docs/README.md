# Quinsy Studio manual

This folder is the book. Read it when you want to know what the studio is, which loop you are in, or what a command actually does. The other files in the repo are the script the agent follows and the story of one product. This manual is for you.

You talk. The agent runs `./studio`. You do not have to memorize the commands. When something is unclear, start here.
