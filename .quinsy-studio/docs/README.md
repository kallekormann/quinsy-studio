# Quinsy Studio manual

This folder is the reference. Read it when you want to know what the studio is, which loop you are in, what you are supposed to sign, or what a command does.

You talk. The agent runs `./studio`. You do not have to memorize the commands.

The files under `process/` are the spec the agent follows. This folder is the explanation. When you need a checklist the agent will not skip, the chapter links to that spec.
